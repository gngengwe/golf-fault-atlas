# The Golf Fault Atlas

An illustrated flipbook: thirteen golf mistakes every golfer recognizes, each with what causes it, how it's fixed, and what tool actually helps.

Static site, no build step. Deployed via Cloudflare Pages at [golf-fault-atlas.ngengwe.com](https://golf-fault-atlas.ngengwe.com).

Rough-sketch stage — early feedback draft, illustrations are first-pass AI generations, not final art.
